# Nordic

多平台 NAS 音乐播放器。连接你自己的音乐服务器,在任意设备上听自己的库。

- **音源**:Navidrome、Subsonic / OpenSubsonic、飞牛音乐(fnOS)
- **多线路**:同一个音乐库可配多条地址,自动测速择优,线路故障自动切换
- **转码播放**:按网络情况选择原始音质或转码码率
- **平台**:Android、iOS、Windows、macOS、Linux、Web(单一 Flutter 代码库)

## 当前阶段:M0 — 原型

正式开发尚未开始。当前只有一个 HTML 原型,用于确认界面结构与视觉方向。**原型未经确认不进入开发。**

```
prototype/
  index.html    设计板:所有屏并排铺开,一屏看全貌
  player.html   可点击交互流:能在浏览器里走完整条核心链路
  styles.css    设计 token 与组件样式
  app.js        假数据、屏幕模板与交互
```

双击 `prototype/index.html` 即可打开,无需构建、无外部依赖。

原型覆盖的核心链路:

> 填服务器(含多条线路)→ 线路测速择优 → 音乐库(专辑 / 艺人 / 歌曲 / 歌单)→ 专辑详情 → 播放页 → 转码质量切换 → 播放队列 / 歌词
